Guest users are permitted to search products, scan packaging labels, and view establishment profiles without inputting login credentials. Main Features based on Title:
Halal Logo Scan and Authentication Module
Target: Visual Halal Seals or Logos on the product packaging
Core Technical Stack/Tools to use: YOLOv8-Nano + EasyOCR + OpenCV + Supabase Relational Tables.
Operational Execution/Function: OpenCV initializes frame acquisition from the camera and adjusts contrast levels. YOLOv8-Nano functions as the visual localization tool, identifying the presence of a halal emblem and outputting a precise bounding box coordinate to crop the Region of Interest (ROI). Immediately following localization, EasyOCR sweeps the cropped box region to read the alphanumeric certificate or license registration tracking code. The system then queries this extracted string against the hcb_registry database table in Supabase. If a matching code is found linked to an accredited body (like IDCP or ZPHCB) and is within its expiration boundary, the system yields a verified AUTHENTICATED output state; otherwise, it warns of an UNVERIFIED/DOUBTFUL label configuration.
Ingredient Scanning and Additive Parsing Module
Target: Printed Text Blocks (E-Numbers) / Ingredients Listed; Block arrays of text specifying ingredients and scientific names on product wrappers.
Tools to use: EasyOCR + OpenCV + Supabase Reference Tables.
Action or Function: OpenCV applies adaptive grayscale thresholding and noise filtering to clean up wrinkled or skewed text lines on product packages. EasyOCR parses the entire character row array to extract text strings, specifically isolating numeric E-number expressions (e.g., "E120", "E471"). The application extracts these isolated text blocks and checks them against the master additives reference dictionary on Supabase via high-speed API lookups. The screen instantly reflects the calculated product status banner based on database matching rules.
Label Configuration
HALAL: purely plant-based, synthetic, or mineral-derived additives that are strictly permissible.
HARAM: additives that are derived from strictly prohibited sources like swine/pork products or non-dhabihah animals.
DOUBTFUL/UNVERIFIED: additives whose halal status depends entirely on the raw material source origin (animal fat vs. vegetable fat), and cannot be determined by text extraction alone.

Halal Certification Document Verification Module
Target: Uploaded physical paper certificates or license sheets (PDF/PNG/JPEG) submitted by establishments.
Tools to use: YOLOv8-Nano + EasyOCR + OpenCV + Supabase Storage Engine.
Action or Function: Instead of relying on a mismatched, third-party framework dependency like PaddleOCR, this module shares our core lightweight architecture. When an establishment certificate image is uploaded, YOLOv8-Nano performs structural layout segmentation, locating and cropping the bounding box areas containing the Certifying Authority Header, the Business Name Row, the Accreditation Number Box, and the Official Verification Seal. EasyOCR is then targeted at these specific cropped box matrices to extract the data text strings without needing to process irrelevant sections of the page. The system cross-references these extracted names and license numbers against the backend hcb_registry records to assist administrators during the validation phase.
Match: Cross-references extracted accreditation numbers and business names against the hcb_registry table in Supabase. Before the admin will filter, it will be labeled PENDING VERIFICATION and then will be flagged as VERIFIED or REJECTED based on credential match and validity period.
